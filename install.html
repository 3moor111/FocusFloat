Download APK How to install

Steps

  1. Download the APK on your Android phone or tablet with the button above.
  2. Open the downloaded file. If Android asks, allow your browser or file manager to install unknown apps, then go back and tap Install.
  3. Open FocusFloat and create an account with Google or with email and password.
  4. Finish setup. Home › Up next › Finish setup (or More › Setup) lists each permission with an Allow button and its status.
  5. Turn on ScrollStop if you want it: More › ScrollStop › Open Accessibility settings, then switch on FocusFloat ScrollStop.

FocusFloat for Windows and Mac

The floating timer on your computer: it stays above your PDF, slides and browser while you study.

Download for Windows Download for Mac

The Mac download is for Apple silicon (M1 and newer). A version for older Macs with an Intel chip is coming soon. Not sure which you have? Apple menu › About This Mac shows “Chip: Apple…” or “Processor: Intel…”.

Windows 10 or 11

  1. Open the downloaded .msi file and follow the installer.
  2. If Windows says “Windows protected your PC”, click More info, then Run anyway. It appears because the app isn’t signed with a paid certificate yet.
  3. Open FocusFloat from the Start menu.

Mac (macOS 11 or newer)

  1. Open the downloaded .dmg and drag FocusFloat into Applications.
  2. The first time, right-click FocusFloat in Applications and choose Open, then Open again. If macOS still refuses, go to System Settings › Privacy & Security and click Open Anyway.
  3. After that it opens normally.

Getting updates

Inside the app (3.9 and newer)

When a new version is out, Update available appears in Up next on Home. Tap it, and FocusFloat downloads the update, checks the file, and opens Android’s installer. You can also check any time in More › Check for updates. The first time, Android asks you to allow FocusFloat to install apps.

With Obtainium

Prefer a separate updater? Install Obtainium, tap Add App, and paste https://github.com/3moor111/FocusFloat. It tells you when a new release is out.

By email

On the GitHub page, choose Watch › Custom › Releases to get an email for each new version.

Updates install over the version you have and keep your progress, cards and settings. Coming from 3.8? Install 3.9 once from this page; after that, updates come to you.

If something won’t switch on

Notification access or Accessibility is greyed out (Android 13+)

Apps installed from an APK need one extra step. Open Settings › Apps › FocusFloat (App info), tap ⋮ at the top right, choose Allow restricted settings, then try again. FocusFloat’s setup screen has an Open App info button for this.

The timer or blocker stops after a while

Samsung, Xiaomi, Oppo, Vivo, Huawei and similar phones may close background apps. Allow Autostart and set battery to Unrestricted for FocusFloat.

A blocked app still opens for a moment

FocusFloat checks the screen twice a second, so a blocked app can show for about half a second before the block screen appears. Make sure Usage access is on.

ScrollStop missed a Reels tab

Apps change their screens. Open More › ScrollStop › Scan this screen, open the missed screen within 10 seconds, then Send last scan.

Is the APK safe?

Compare the file’s SHA-256 with the one shown above. Every release on this site is signed with the same FocusFloat key, so later versions install over this one and keep your data.
